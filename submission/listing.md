## Long description

Evaluate MailChannels and implement its Email API with official JavaScript,
Python, and PHP SDK guidance. Add production controls for sender domains,
signed webhooks, suppressions, multi-tenant operations, quotas, credentials,
metrics, and safe automated sending. Selection guidance remains neutral and
identifies unsupported requirements instead of forcing MailChannels.
